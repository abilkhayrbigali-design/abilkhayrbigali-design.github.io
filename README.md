### Повторная проверка

Самому сайту Node.js и установка пакетов не нужны. Для автоматической проверки
в браузерах установите инструменты разработчика и запустите:

```sh
npm install
npx playwright install chromium firefox
npm test
BROWSER_ENGINE=firefox npm test
```

Для уже установленного Chromium можно использовать
`BROWSER_PATH=/usr/bin/chromium npm test`.
Проверка запускает временный локальный сервер и отдельный профиль браузера.
Сценарии в `tests/assignment4.cjs` проверяют девять страниц на ширинах 375, 768
и 1440 px, все новые функции, мобильное меню, карусель, клавиатуру, отсутствие
отправки форм и ошибок браузера. Дополнительно проверяются смена года в часах,
reduced motion и открытие сайта напрямую через `file://`.
Результаты и снимки компонентов сохраняются в `report/assignment4/`.

Проверка 21 октября 2026 года: успешно пройдены 51 сценарий в Chromium
154.0.8037.97 и 51 сценарий в Firefox 153.0 (102 суммарно). Ошибок браузера,
неожиданных отправок форм, сломанных изображений и горизонтального переполнения
на проверенных ширинах не обнаружено. Снимки мобильной и настольной версии
новых компонентов также просмотрены вручную.

## Для защиты

- Media query меняет стили, когда ширина viewport достигает указанного порога.
- Mobile-first: базовый стиль для телефона; `min-width` расширяет макет.
- Bootstrap делит строку на 12 долей: `col-lg-6` = половина, `col-lg-4` = треть.
- `g-4` задаёт промежутки сетки; `p-4` - внутренний отступ; `mt-lg-5` - верхний отступ от large.
- `data-bs-target` связывает кнопку с `id` раскрывающегося меню или карусели.
- `aria-expanded` сообщает состояние меню; `aria-current` отмечает текущую страницу.
- Bootstrap 5.3 использует `card-group`; устаревший `card-deck` не нужен.

Официальная документация: https://getbootstrap.com/docs/5.3/
